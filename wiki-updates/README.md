# Wiki Updates

This directory contains proposed updates to the GitHub Wiki pages.

## How-To-Update-Node.js.md

**Changes Made:**
- Added a section explaining how to update to a newer major version of Node.js
- Added example showing `sudo hb-service update-node 24` to update to Node.js 24.x
- Clarified that specifying just the major version number (e.g., 24) will install the latest available version of that major release

**Instructions for Maintainers:**
Please copy the contents of `How-To-Update-Node.js.md` to the corresponding wiki page at:
https://github.com/homebridge/homebridge/wiki/How-To-Update-Node.js

**Related Issue:**
This addresses the user feedback that the wiki didn't clearly explain how to jump to a major version of Node.js.
