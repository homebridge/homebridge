## Manage Stable Version

### Using Homebridge UI:

You can manage the Homebridge version from the Homebridge UI:

1. Click the current Homebridge version on the Status page.
2. Select the desired Homebridge version.
3. Click Install.

![change-homebridge-version](https://user-images.githubusercontent.com/3979615/96521915-15936700-12be-11eb-9826-f19b201d20db.gif)

Restart Homebridge to take effect.

### Using Command Line:

To install the latest version:

```bash
$ sudo npm install -g --unsafe-perm homebridge@latest
```

Restart Homebridge to take effect.

To install a different version of Homebridge, replace the `1.2.0` with the version you wish to install. See [past releases](https://www.npmjs.com/package/homebridge?activeTab=versions) of Homebridge on `npmjs.com`.

```bash
$ sudo npm install -g --unsafe-perm homebridge@1.2.0
```

Restart Homebridge to take effect.

## Manage Beta Version

### Using Homebridge UI:

You can use the same method as above:

![change-homebridge-version](https://user-images.githubusercontent.com/3979615/96521915-15936700-12be-11eb-9826-f19b201d20db.gif)

Restart Homebridge to take effect.

### Using Command Line:

To install the beta version:

```bash
$ sudo npm install -g --unsafe-perm homebridge@beta
```

Restart Homebridge to take effect.

### Updates

If you are currently running a beta version of Homebridge you will receive an update notification in the [Homebridge UI](https://github.com/homebridge/homebridge-config-ui-x) when a new stable or beta build is released.
