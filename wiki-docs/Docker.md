The following guides provide instructions showing how to run Homebridge in Docker on various platforms:

* [[How to setup Homebridge with Docker on Linux|Install Homebridge on Docker]]
* [How to setup Homebridge with Docker on a Raspberry Pi](https://github.com/homebridge/docker-homebridge/wiki/Homebridge-on-Raspberry-Pi)
* [How to setup Homebridge with Docker on a Synology NAS](https://github.com/homebridge/docker-homebridge/wiki/Homebridge-on-Synology)
* [How to setup Homebridge on a Synology NAS using DSM Package Center](https://github.com/homebridge/homebridge-syno-spk#how-to-install)
* [How to setup Homebridge with Docker on LibreELEC](https://github.com/homebridge/docker-homebridge/wiki/Homebridge-on-LibreELEC)

Homebridge **does not work** when running in Docker for Mac or Docker for Windows due to [this](https://github.com/docker/for-mac/issues/68) and [this](https://github.com/docker/for-win/issues/543).
