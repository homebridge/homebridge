# 3rd Party: Homemanager App

The Homemanager App uses the official Homebridge UI API to provide a native Homebridge management experience on iOS.
Its focus is on managing multiple servers and bridges at one place along with interactive guides, helping beginners with setting up their Homebridge system. Features as swipe gestures and visual config editing also for non schema plugins, makes config editing easy and convenient. Many more small and bigger [features](https://www.homemanager-app.de/features) to discover.
